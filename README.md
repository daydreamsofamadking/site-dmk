# Daydreams of a Mad King — site officiel

Page vitrine du groupe DMK, publiée sur https://daydreamsofamadking.com via Netlify.

- `index.html` : la page. La liste des concerts est dans le script en bas du fichier (tableau `shows`) : une ligne par date, les dates passées disparaissent toutes seules.
- `img/` : logo et photos.
- `audio/` : titres en écoute sur la page.

Chaque modification poussée sur la branche `main` est mise en ligne automatiquement par Netlify.
